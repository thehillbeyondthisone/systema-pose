# Shared 3D scene prototype

The processed 18–30 second pilot now has a real PromptHMR moving-camera reconstruction of all four participants. Open http://127.0.0.1:8770/scene.html while the teaching server is running. The viewer supports dragging to orbit, zoom/pan, front/side/overhead presets, participant visibility, synchronized footage, 30 fps frame stepping and slower playback. The existing pilot lesson links to it through “View in 3D”. Instructor upload and passage selection remain available in the teaching suite.

`scene.json` contains 360 frames of 22-joint XYZ skeletons in shared world coordinates. `reconstruction-reviewed-ids/world4d.glb` and `world4d.mcs` contain animated mesh exports. The source hash and mapping (original frames 540–899), provenance and output locations are recorded in `manifest.json`. Model assets and checkpoints are not served by the application.

This is an exploratory reconstruction. Metric scale, relative depth and contact are unverified. Nine source-camera reprojection anchors were inspected. Fading is a tracking warning, not measured visibility. Compare the source before interpreting contact.
